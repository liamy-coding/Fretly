# 弦格 Fretly — 练习页 UI 改造需求规格（播放器化）

> 项目根：`fretly/` ｜ 范围：练习页 UI + 六线谱渲染 ｜ 硬约束：零后端 / 零云端 / 断网可用 / 不限次免费

## 0. 合规前提（先读）

- **允许**：借鉴成熟 tab 播放器的**布局与交互设计**——界面风格、信息层级、控制分组、播放跟随等。设计语言与交互范式不受版权保护。
- **禁止**：复制任何第三方的代码、CSS、图标资源、图片素材、品牌标识；不得出现他方品牌名/logo，不得暗示与本产品存在官方关联。
- **禁止**：实现任何「绕过他方付费墙 / 抓取其内容」的功能。本产品所有曲谱来自用户自有导入或内置示例。
- 本文档中「参考站点」仅作为设计讨论的语境，**不出现在任何产品文案、注释或可访问标识中**。所有实现原创。

## 1. 改造目标

**从「分页式谱面 + 一行挤满控件的工具栏」改成「单行横向谱面 + 自动跟随的固定播放控制条」。**

对初学者的价值：① 演奏时不用再腾出手横向拖动找位置，眼睛永远盯在当前小节；② 控制项从「找得到」变成「记得住位置」（播放固定在左、速度固定在中、开关固定在右）；③ 装饰极简，谱面占最大面积，降低视觉负担。

## 2. 要学的 5 个关键点（及原创实现）

| # | 可借鉴的设计 | 原创实现 |
|---|---|---|
| 1 | 谱面单行横向排列，视觉主角 | 扩展现有 `layoutTab` 加单行模式，仍用双 Canvas，不引入渲染库 |
| 2 | 当前小节自动跟随滚动 | `useRaf` overlay 帧内直读 `practiceController.currentTick` 驱动 `scrollLeft`，不新增状态层 |
| 3 | 顶部紧凑信息栏 | 复用现有页头，补 `tab.key` / `tab.capo` / 拍号（字段已存在，无需扩展模型） |
| 4 | 控制项分组 | flex 分三组 + 组间分隔线，**不新增组件**，仅重排 `PracticeToolbar` 现有子元素 |
| 5 | 播放位置强反馈 | 复用已有小节底色 + 播放头，改为「跟随视口内高对比 + 其余小节降透明度」 |

## 3. 明确不做

不做账号 / 登录 / 云同步 / 社交 / 分享 / 排行榜；不做曲库联网检索或在线抓谱；不做付费墙、额度、剩余次数（架构守卫已禁文案）；不做音频变速变调（`playbackRate` 全局禁用）；不复制任何第三方素材与图标；不改 `TranscribePage` / `LibraryPage` / `DashboardPage` / `SettingsPage` 的视觉体系。

## 5. 自动跟随滚动的交互定义（核心）

### 5.1 播放时如何滚动
- **锚点**：视口宽度 **左侧 1/3 处**（移动端为 **1/2 处**，屏幕窄，居中更稳）。
- **方式**：**连续平滑**（每帧按当前小节 x 与锚点的差值做缓动逼近），**不是跳格**。跳格会让初学者在换行/换小节时丢失位置感。
- **越界规则**：仅当当前小节 x 超出「锚点 ± 半屏安全带」时才启动滚动；带内不移动，避免播放头微动导致画面持续漂移。
- **减速**：播放速度 ≤ 60% 时，缓动系数减半，跟随更「软」，减少眩晕。

### 5.2 手动滚动时是否暂停跟随
**是，自动解除跟随。** 用户任何 `wheel`/触摸拖动/滚动条操作立即进入「自由浏览」状态：立即停止自动滚动，并在谱面右上角浮出 **「▶ 恢复跟随」** 胶囊按钮（点击后平滑滚回当前小节并恢复跟随）。播放**不中断、不暂停**——初学者常暂停去回看，不该因为看一眼前面就丢掉音频。再次点击播放/暂停/切小节时**自动恢复跟随**。

### 5.3 停止播放时滚动如何复位
- **暂停**：**不复位**，保持在当前位置（便于就地回看），跟随状态保留。
- **回开头**（`seek(0)`）/ **切换曲目**：滚动平滑复位到 `scrollLeft = 0` 并强制恢复跟随。
- **焦点跳转**（`focusMarker` / `?focus=N`）：先定位到目标小节，再恢复跟随，不停留在旧位置。

### 5.4 布局：4 小节折行 → 单行横向？**结论：改，但用兼容方式改**

**结论：练习页采用单行横向布局。** 理由与成本控制：
- **体验收益是决定性的**：折行布局下，越到曲子后段，且「当前小节在视野内」这一基础需求会因跨行而失效，跟随滚动无法有意义地实现。不做单行，整个改造不成立。
- **成本可控**：`layoutTab` 是纯函数，改造方式为**新增可选参数** `layoutTab(measureCount, { singleRow: true, firstRowMeasures: 2 })`，**默认行为完全不变**。现有 5 条 `tabRender.test.ts` 断言（`barlineYOf` / `strumVisualTicks` / `stringYOf` / `contentXOf`）全部保持通过，仅新增单行模式的断言。
- **配套**：仅练习页传 `singleRow`；编辑器页继续用默认折行，零影响。
- **换行处补一次「行首谱号/弦名 + 小节号」**，避免长谱面横向滚动时无法定位（`drawTab` 已按 `box.x === 0` 画弦名，单行模式下改为按「每 N 小节重复画小节号」）。

### 5.5 架构守卫（必须不破坏）
- 变速仍走 `practiceController.setRatio` → `Transport.setTempo`，**全项目仍无 `playbackRate`**。
- 滚动计算只做 x 坐标平移，**不涉及 `6 - x`**；弦向换算仍只在 `core/fretboard.ts`。
- 熟练度仍只在 `SessionEnded` 由 `reducePractice` 重算；本次不改任何事件派发路径。

## 6. 响应式要求

| | 桌面（≥1024px / `xl`） | 移动端（<1024px） |
|---|---|---|
| 信息栏 | 单行：曲名 + 作者 · BPM · 调 · 变调夹 · 拍号 | 曲名一行，元信息折叠为第二行小字 |
| 谱面高度 | 单行谱面，`min-h` 保证 ≥ 2 行谱面高度，避免大片留白 | 谱面占首屏主体，`h` 自适应，滚动条隐藏 |
| 右栏 | 保留 `240px` 右栏（接下来 / 渐进 / 难点） | 右栏下沉到谱面下方，「接下来」改为横向滑动条 |
| 控制条 | 三组水平排列，组间竖线分隔 | 两组：第一行「播放 + 速度」，第二行「循环 + 节拍器 + 示范」 |
| 跟随锚点 | 左 1/3 | 居中 1/2 |
| 触摸 | 支持横向拖动（`touchAction` 保留） | 拖动时禁用跟随，松手后 3s 自动恢复（若未点「恢复跟随」） |

## 7. 验收标准（可检验）

1. **跟随**：播放到第 5 小节时，第 5 小节完整处于视口内且靠左 1/3（移动端居中），并有当前小节底色高亮。
2. **连续性**：从第 4 号小节播放到第 20 号小节全程，画面**无跳帧式横移**，播放头不离开视口。
3. **手动滚动**：播放中横向拖动谱面，自动滚动立即停止，出现「恢复跟随」按钮；点击后平滑回到当前小节并恢复跟随。
4. **不中断**：上述手动滚动与恢复过程中，`isPlaying` 保持为 `true`，音频无卡顿。
5. **复位**：点「回开头」后 300ms 内 `scrollLeft === 0`，且跟随状态为「开启」。
6. **控制条**：桌面宽度下，播放/暂停按钮位置不随速度滑块数值变化而位移（分组固定）。
7. **信息栏**：显示曲名、作者、BPM、调性、变调夹、拍号六项，且均来自 `Tab` 字段，无硬编码。
8. **回归**：`npm test` 全绿，`archGuard.test.ts` 三条守卫（`6 - x` / `playbackRate` / core 层依赖）全部通过；`tabRender.test.ts` 原有 5 条断言无一修改。
9. **合规扫描**：源码不存在第三方品牌名、外链素材 URL、付费/额度类文案。
10. **断网**：全程 DevTools 离线状态下功能可用，无任何网络请求（`Network` 面板为空）。
